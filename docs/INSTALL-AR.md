# تثبيت وتجربة الإصدار 1.5.0

حمّل `katilim-finans-chrome-v1.5.0.zip` من [إصدارات GitHub](https://github.com/EnesAhmet10000/katilim-endeks-checker/releases/tag/v1.5.0)، وفك ضغطه في مجلد ثابت. ملف ZIP نفسه لا يُختار في Load unpacked؛ اختر المجلد الذي يحتوي على `manifest.json`.

اختر **العربية** أو **English** أو **Türkçe** من قائمة اللغة في نافذة الإضافة أو بطاقة النتائج. يُحفظ اختيارك محليًا، والعربية تُعرض من اليمين إلى اليسار. قائمة النقر الأيمن تتبع اللغة المختارة.

1. افتح `chrome://extensions` وفعل Developer mode.
2. اختر Load unpacked ثم المجلد الذي فككت فيه ZIP. عند البناء من المصدر اختر `apps/extension/dist/chrome`. لتحديث تثبيت سابق، فك النسخة الجديدة في مجلد التثبيت نفسه ثم اضغط Reload.
3. أعد تحميل صفحة الاختبار أو صفحة بحث Google. حدد `Petkim` أو `PETKİM` أو `BIST:PETKM` ثم اضغط كلك يمين واختر Katılım Uygunluğunu Kontrol Et.
4. ينبغي أن يظهر الرمز `PETKM`. زر KAP يفتح صفحة الشركة التي تتضمن رقمها، وHelal Finans يفتح `/hisseler/PETKM`.
5. زر Yenile يعيد جلب الأدلة والمصادر. تاريخ الفحص يختلف عن تاريخ ملف المؤشر والفترة المالية وتاريخ توزيع الصندوق؛ تظهر تواريخ المصادر منفصلة.

الإضافة تعمل دون تشغيل localhost أو API. دليل الشركات يُفحص عند الطلب كل 24 ساعة، وعضوية الشركة تُخزن ساعة واحدة. زر التحديث يتجاوز المدتين. فشل الجلب بعد انتهاء صلاحية العضوية يعرض «Güncel veri doğrulanamadı»؛ لا يحول عدم وجود بيانات إلى عدم توافق.

الدليل المحلي المؤرخ 12 أكتوبر 2026 يحتوي 803 رموز ومعرفات شركات كما وردت في دليل KAP، منها رموز متعددة لبعض الشركات. هو دليل هوية وروابط فقط، وليس قائمة أسهم متوافقة.

دليل الصناديق العام يضم 3,523 رمزًا كما وردت في KAP، ويتحدث عند الطلب كل 24 ساعة. يمكنك اختيار رمز مثل KUA أو TTE أو الاسم الكامل للصندوق. عند تكرر الرمز بين سهم وصندوق، اختر النوع الصحيح. يدعم `BIST:CODE` الأسهم و`FON:CODE` الصناديق صراحة. تظهر روابط KAP الأصلية للصناديق أيضًا، ويُقرأ نوع المظلة من الصفحة الرسمية عند توفره. معرفة هوية الصندوق لا تعني أنه متاح للتداول على TEFAS.

النتيجة تقرأ قائمة BIST المؤرخة وحقول KAFİF المالية للشركات، أو بيانات تسجيل الصندوق ونوع المظلة وملف TEFAS وتوزيع أنواع الأصول حيث تتوفر. يظهر النقص دون تعويضه بأرقام. وثائق الإجازة والمكونات التفصيلية لا تزال تتطلب مراجعة؛ لا يصدر حكم حلال/حرام نهائي آلي. روابط Helal Finans وFintables للمراجعة اليدوية، ولا تُنسب إليهما نتيجة لم تُجلب. راجع RELEASE-1.3.0-AR.md لحدود التغطية.

قيود الصفحات: Chrome يمنع الحقن في صفحاته الداخلية والمتجر وبعض عارضات PDF. استخدم بحث نافذة الإضافة هناك. الأذونات تستخدم activeTab للحقن بعد طلب المستخدم، وليس قراءة جميع الصفحات تلقائيًا.

الحزمة منشورة على GitHub Releases للتثبيت المحلي؛ لم تُنشر الإضافة في Chrome Web Store. إصدار 1.4.3 يصلح قراءة الفترات السنوية، ويتضمن [تقرير فحص 30 سهمًا](AUDIT-30-2026-10-13.md).
