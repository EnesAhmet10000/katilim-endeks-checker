# تجربة الإصدار 1.1.0

1. افتح `chrome://extensions` وفعل Developer mode.
2. إذا كانت النسخة السابقة محملة من نفس مجلد المشروع، اضغط Reload. وإلا اختر Load unpacked ثم `apps/extension/dist/chrome`.
3. أعد تحميل صفحة الاختبار أو صفحة بحث Google. حدد `Petkim` أو `PETKİM` أو `BIST:PETKM` ثم اضغط كلك يمين واختر Katılım Uygunluğunu Kontrol Et.
4. ينبغي أن يظهر الرمز `PETKM`. زر KAP يفتح صفحة الشركة التي تتضمن رقمها، وHelal Finans يفتح `/hisseler/PETKM`.
5. زر Yenile يعيد جلب الدليل وصفحة الشركة. تاريخ الفحص هو وقت قراءة الصفحة، وليس تاريخ إصدار تقرير مالي.

الإضافة تعمل دون تشغيل localhost أو API. دليل الشركات يُفحص عند الطلب كل 24 ساعة، وعضوية الشركة تُخزن ساعة واحدة. زر التحديث يتجاوز المدتين. فشل الجلب بعد انتهاء صلاحية العضوية يعرض «Güncel veri doğrulanamadı»؛ لا يحول عدم وجود بيانات إلى عدم توافق.

الدليل المحلي المؤرخ 12 أكتوبر 2026 يحتوي 803 رموز ومعرفات شركات كما وردت في دليل KAP، منها رموز متعددة لبعض الشركات. هو دليل هوية وروابط فقط، وليس قائمة أسهم متوافقة.

النتيجة تقرأ العضوية المعروضة في صفحة KAP. لا تزال مطابقة قائمة BIST المؤرخة وجلب نماذج KAFİF المالية وبيانات الصناديق غير موصولة. لذلك لا تعرض هذه النسخة نسبًا مالية أو حكم حلال/حرام نهائيًا. روابط Helal Finans وFintables للمراجعة اليدوية، ولا تُنسب إليهما نتيجة لم تُجلب.

قيود الصفحات: Chrome يمنع الحقن في صفحاته الداخلية والمتجر وبعض عارضات PDF. استخدم بحث نافذة الإضافة هناك. الأذونات تستخدم activeTab للحقن بعد طلب المستخدم، وليس قراءة جميع الصفحات تلقائيًا.

الحزمة ZIP للاختبار المحلي والتحضير للمتجر؛ لم تُرفع أو تُنشر. الحزمة القديمة `katilim-finans-chrome-v1.0.0.zip` محفوظة دون تغيير.
