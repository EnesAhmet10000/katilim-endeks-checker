# مصادر بيانات Katılım Endeksi Checker

هذا التقرير يسجل مرحلة البحث. التحديث اللاحق 1.3.0 دمج المصادر مباشرة في الإضافة دون خادم أو اشتراك؛ التفاصيل في [ملاحظات الإصدار](RELEASE-1.3.0-AR.md). الاقتراحات السابقة أدناه محفوظة كسجل بحث وليست حالة المنتج الحالية.

فحص مباشر بتاريخ 12 أكتوبر 2026. المقصود معلومات الأسهم والصناديق التركية اللازمة للفحص، وليس أسعار التداول وحدها.

## القرار المقترح

أوصي بخدمة API صغيرة للمشروع تجمع ثلاثة مصادر: **Borsa İstanbul CSV للعضوية، KAP KAFİF لبيانات الشركات، وTEFAS JSON لبيانات الصناديق وتوزيع أنواع الأصول**. مشاريع GitHub مفيدة لاكتشاف المسارات وأساليب الطلب، لكن تغطيتها أو أسماؤها لا تثبت اكتمال البيانات المطلوبة. خدمات الفحص العالمية ليست بديلًا مثبتًا لتغطية BIST وقواعده.

هذا تقرير بحث وتجارب قراءة بيانات. لم أغير مسار البيانات في الإضافة ولم أنشر API أو أنشئ حسابات أو أرسل مراسلات أو أشغل تحديثًا دوريًا.

## نتائج الاختبارات المباشرة

### 1. عضوية مؤشرات المشاركة — مصدر رسمي

المصدر: [Borsa İstanbul CSV](https://borsaistanbul.com/datum/hisse_endeks_katilim_ds.csv). رابط القائمة منشور في [صفحة مؤشرات المشاركة الرسمية](https://borsaistanbul.com/katilim-esasli-paylar-ve-pay-endeksleri).

أعاد الطلب HTTP 200. الملف يفصل الحقول بعلامة `;`، وله سطر عناوين تركي وآخر إنجليزي. قرأت 516 صف عضوية، كلها تحمل تاريخ `12/10/2026`. الصفوف تتكرر بين المؤشرات، فلا تمثل 516 شركة مختلفة.

| المؤشر | صفوف المكونات في الرد المفحوص |
|---|---:|
| XKTUM | 238 |
| XK100 | 100 |
| XK050 | 50 |
| XK030 | 30 |
| XK030EA | 30 |
| XSRDK | 27 |
| XKTMT | 41 |

التنفيذ المقترح يحذف لاحقة `.E` من رمز الشركة، ويحتفظ بتاريخ الملف ورمز المؤشر الرسمي. لا ينبغي تخمين العضوية من تجاوز نسبة مالية؛ قواعد البورصة تتضمن أحكامًا تتعلق بفترات التقييم والهامش الانتقالي.

### 2. نسب ومؤشرات KAFİF — بيانات منشورة من KAP

المصدر المكتشف في borsa-mcp: [جدول KAP المجمع](https://www.kap.org.tr/tr/kfifAllInfoListByItem/KPY97SummaryGrid).

أعاد HTTP 200، ونجح استخراج 573 سجلًا من جدول HTML المعروض دون تشغيل JavaScript المنشور. الأعمدة تتضمن الرمز، اسم الشركة، عملة العرض، السنة/الفترة المالية، نوع القوائم، أربعة أسئلة متعلقة بالنشاط والامتياز والدعم، ونسب الإيرادات والأصول والديون غير المناسبة.

عينة PETKM من الرد تحمل فترة `2026 / 6 Aylık` ونسبًا `0,25` للإيراد و`2,99` للأصول و`24,19` للديون. هذه عينة تثبت اختلاف المصدر الحقيقي عن النسب الافتراضية القديمة، وليست توصية استثمار أو فتوى. عينات إضافية من BIMAS وSASA وTHYAO وASELS محفوظة في ملف الأدلة.

عدد السجلات لا يثبت وجود نموذج لكل رمز شركة. لا يوجد في هذا الاختبار ربط لكل سجل بمعرف إفصاح منفصل أو إثبات لتاريخ نشره. وقت الجلب يجب أن يبقى منفصلًا عن الفترة المالية، وتحتاج المرحلة التالية مقارنة الجدول بتبويب Katılım Finans في صفحات الشركات وإفصاحاتها.

### 3. TEFAS — JSON يعمل رغم رفض صفحة HTML

اختبرت الطلبات التالية دون API key، وبالتحقق الطبيعي من شهادة HTTPS:

| المسار | الطريقة | نتيجة عينة KUA |
|---|---|---|
| `/api/funds/fonBilgiGetir` | POST JSON: `fonKodu` | HTTP 200؛ اسم الصندوق وفئته والسعر وحجم المحفظة وعدد المستثمرين |
| `/api/funds/fonProfilBilgiGetir` | POST JSON: `fonKodu`, `dil` | HTTP 200؛ ISIN ورابط KAP وحالة توفره على TEFAS والرسوم والمدة والمخاطر |
| `/api/funds/dagilimSiraliGetirT` | POST JSON؛ الرمز والنوع ونطاق تاريخي | HTTP 200؛ ثمانية صفوف ضمن نطاق 1–12 أكتوبر، أحدثها 12 أكتوبر 2026 |

المسارات تحت `https://www.tefas.gov.tr`. تفاصيل الطلب والتصنيف موجودة في ملف provider المشار إليه، وأجسام الردود الملخصة محفوظة في ملف الأدلة. رد توزيع الأصول يستخدم رموزًا مثل `hs` و`kkstl`؛ يجب التحقق من قاموسها، وإبقاء أي رمز غير معروف دون تفسير تخميني.

هذا توزيع **أنواع الأصول**، وليس أسماء كل سهم أو ورقة مالية داخل الصندوق. صناديق الأسهم وصناديق الصناديق تتطلب متابعة المكونات أو تقرير توزيع المحفظة من KAP. و`faizIcerigi: null` في ملف KUA قيمة غير متاحة، وليست تصريحًا بعدم وجود فائدة.

التوثيق الذي راجعته في borsapy يذكر قابلية HTTP 429 عند كثرة الطلبات؛ لم أقس حد الاستخدام. النجاح الحالي لا يثبت اتفاقية مستوى خدمة أو حق إعادة توزيع البيانات. وثبت نجاح KUA فقط في هذه التجربة للـJSON، وليس كل رموز الصناديق.

## مسار رسمي للإنتاج

[MKK API Portal](https://apiportal.mkk.com.tr/) مدخل رسمي لاكتشاف واختبار الخدمات، ويتطلب إنشاء حساب واعتماده وتسجيل تطبيق للحصول على مفتاح، بحسب [إعلان MKK](https://www.mkk.com.tr/haberler/mkk-api-portal-yayinda).

أما [وثيقة خدمة نشر بيانات KAP الرسمية](https://www.kap.org.tr/tr/api/about/content-file/8a019492945fbe080194b26d8bed4873) فتذكر خدمات قوائم وتفاصيل الشركات والصناديق والإفصاحات والمرفقات، وتحدد اتفاقية توزيع بيانات مع Borsa İstanbul، وتفويض عناوين IP وتسليم API key. وتوجّه الطلبات ذات الكثافة العالية إلى الخدمات المتعاقد عليها. لا أعتبر إعلان مجانية تطبيق البوابة دليلًا على مجانية إعادة نشر بيانات الإنتاج أو شمول KAFİF بحقوله الحالية دون فحص المنتج.

هذا المسار يستحق المراجعة قبل إطلاق الإضافة للعامة. لم أطلب حسابًا أو عقدًا أو مفتاحًا بالنيابة عنك.

## كيف نربطها بمشروعك

1. مجمّع خادم يقرأ عضوية BIST وجدول KAFİF، ويخزن نسخة موثقة بدل تحميل الجدول لكل مستخدم.
2. بيانات الصناديق تُجلب عند الطلب مع cache وتحديد معدل الطلبات. الصناديق غير الموجودة في TEFAS تبقى على KAP وتُعرض البيانات المتاحة فقط.
3. API المشروع يعيد هوية الأداة، source URL، وقت الجلب، تاريخ بيانات العضوية، الفترة المالية، الحقول الخام وملاحظات النقص والتعارض.
4. محرك الفحص يميز العضوية الرسمية عن نتائج النسب والوثائق، ولا يحول missing/null إلى صفر أو HAYIR.
5. قبل إعلان تغطية كاملة، نختبر صناديق المشاركة والصناديق العامة والمتداولة والتقاعد والخاصة، والأسهم التي ليس لها سجل KAFİF، ومصادر متعارضة وملفات قديمة.

`borsa-mcp` مفيد لاكتشاف مصدر KAP، لكن كوده يضع قيمًا افتراضية مثل `0,00` و`HAYIR` عند غياب بعض الحقول، ويتحقق من عضوية ثلاثة مؤشرات عبر Mynet. لذلك لا أنصح بنسخ هذه الأجزاء إلى محرك موثوق دون تعديل. كذلك provider TEFAS في borsapy يعطل التحقق من الشهادة؛ اختباراتي هنا نجحت مع التحقق الطبيعي، فلا حاجة لنقل ذلك السلوك.

ترخيص كود borsa-mcp هو MIT، وborsapy وborsajs يعرضان Apache-2.0. الوثائق في الأخيرين تذكر قيودًا متعلقة بالاستخدام التجاري وبيانات المصادر؛ يلزم فصل صلاحية استعمال الكود عن شروط استعمال البيانات. لم أدمج أي كود خارجي في الإنتاج.
