# Katılım Endeksi Checker 1.5.0

**Your language. Your view. Official sources.**

- Arabic, English and Turkish UI in both the popup and result card.
- Right-to-left Arabic layout, translated search, disclosures, warnings, display controls and right-click menu.
- Language choice is saved locally and synchronized across extension views. Switching language does not refetch or change the source evaluation.
- Short README in all three languages, original demo, new Arabic/English screenshots and LinkedIn link.

Download **katilim-finans-chrome-v1.5.0.zip**, extract it, and select its folder through `chrome://extensions` → Developer mode → Load unpacked. Reload an existing installation and the target webpage after updating.

Validation: full build and TypeScript check; engine/API/packaged-worker checks; translation, saved-language and context-menu tests; rendered popup/card checks in Arabic, English and Turkish. Source identity, numeric values and URLs are preserved. Screenshots use the recorded 30-stock audit response; the prior live audit is not a new 1.5.0 market audit.

The original demo is attached as **katilim-demo.mp4**. It predates this release and illustrates the core interaction, not the new language selector.

Free public-source access; no API key, account or tracking. This is a GitHub release for local installation, not a Chrome Web Store publication. Index membership is not a complete religious verdict or investment recommendation. Official names and source-specific text without a matching UI translation remain in their original language.
