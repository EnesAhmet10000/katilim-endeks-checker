# Katılım Endeksi Checker

**Select a ticker. Right-click. See the official data.**

A Chrome extension that brings BIST participation-index membership, company disclosures and available fund data into the page you're already using. Sources: **BIST, KAP and TEFAS**.

**Free. No API key. No account. No tracking.**

[⬇ Download the extension](https://github.com/EnesAhmet10000/katilim-endeks-checker/releases/latest) · [▶ Watch the demo on YouTube](https://youtu.be/j1KZuk8OvZg) · [Download the original demo (MP4)](https://github.com/EnesAhmet10000/katilim-endeks-checker/releases/download/v1.5.0/katilim-demo.mp4)

[![See the extension in action on YouTube](docs/demo-preview.gif)](https://youtu.be/j1KZuk8OvZg)

### Your language. Your view.

- **العربية · English · Türkçe** — switch languages in the popup or result card. Arabic supports right-to-left layout.
- **Simple, full or custom** — see the essentials, every detail, or just the sections you choose.
- **Stocks and funds** — search by name or code, open the sources, and refresh when needed.

### Try it

Download the ZIP and extract it. Open `chrome://extensions`, enable **Developer mode**, then **Load unpacked** and select the extracted folder. Select a ticker on a webpage and right-click to check it.

[Installation guide](docs/INSTALL-AR.md) · [30-stock audit](docs/AUDIT-30-2026-10-13.md)

### العربية

**حدد السهم. اضغط كلك يمين. شوف بياناته من المصادر الرسمية.**

إضافة مجانية للأسهم والصناديق التركية، بواجهة عربية وإنجليزية وتركية. اختر المظهر البسيط أو الكامل، أو خصص ما يظهر لك. البيانات الناقصة تظهر بوضوح.

### Türkçe

**Hisseyi seç. Sağ tıkla. Resmi verileri gör.**

BIST hisseleri ve fonlar için ücretsiz Chrome eklentisi. Türkçe, Arapça ve İngilizce arayüz; basit, tam veya kişiselleştirilmiş görünüm. Kaynakları açın, ihtiyaç duyduğunuzda yenileyin.
